# Habit Tracker Telegram Bot

Интерактивный помощник для формирования и контроля ежедневных привычек. Бот позволяет пользователям оцифровать свои цели, отслеживать прогресс в реальном времени и получать напоминания о запланированных делах.

## 🌟 Основные функции

* **Управление привычками**: Создание, редактирование и удаление персональных целей.
* **Трекинг прогресса**: Удобная отметка о выполнении привычки через систему Inline-меню.
* **Статистика**: Наглядное отображение истории достижений для поддержания мотивации.
* **Умные уведомления**: Настройка напоминаний, чтобы не пропустить ни одного важного действия.
* **Мультипользовательность**: Изолированное хранение данных каждого пользователя в базе данных.

## 🛠 Технический стек

* **Language**: Python 3.10+
* **Framework**: [Telebot](https://pypi.org/project/pyTelegramBotAPI/) 
* **Database**: PostgreSQL / SQLite (через SQLAlchemy или аналоги)
* **Deployment**: Docker, Docker Compose

## 🚀 Запуск проекта

### 1. Настройка переменных окружения

Создайте файл `.env` в корне проекта и добавьте ваш токен бота и данные БД:

```env
BOT_TOKEN=your_telegram_bot_token
DATABASE_URL=postgresql://user:password@localhost:5432/db_name

```

### 2. Запуск через Docker

Самый быстрый способ развернуть бота вместе с базой данных:

```bash
docker-compose up -d --build

```

### 3. Локальный запуск

Если вы хотите запустить проект без контейнера:

```bash
python -m venv venv
source venv/bin/activate  # или venv\Scripts\activate на Windows
pip install -r requirements.txt
python main.py

```
